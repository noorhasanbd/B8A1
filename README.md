# TypeScript Assignment: Problem Solving with TypeScript & OOP

This is my first TypeScript assignment, covering the fundamentals and core concepts of OOP. The problems assess my understanding of TypeScript's primary types, generics, functions, OOP and Promises.

Solutions to all the problems are in `solutions.ts`, as per the assignment guidelines. To keep the file clean, comments and `console.log()` are avoided.

## Files
In this repository I have three files:

- `solutions.ts`: contains the solutions to 8 TypeScript and OOP problems.
- `any-unknown-never.md`: a blog that discusses the `any`, `unknown` and `never` types and when to use them.
- `access-modifiers.md`: a blog discussing the access modifiers that control access to class properties and methods.
